# Dokumentasi Pengujian (Black Box Testing)

Berikut adalah hasil pengujian sistem untuk memastikan fitur-fitur berjalan sesuai dengan skenario yang telah ditentukan:

| No | Fitur | Skenario Uji | Hasil yang Diharapkan | Status |
|:---|:---|:---|:---|:---|
| 1 | Login | Memasukkan username & password yang benar | Berhasil masuk ke halaman dashboard | Berhasil |
| 2 | Login | Memasukkan username atau password yang salah | Muncul pesan error "Login Gagal" | Berhasil |
| 3 | Input Data | Menambah data baru dengan form lengkap | Data tersimpan ke database | Berhasil |
| 4 | Input Data | Mengosongkan form wajib diisi | Muncul peringatan validasi | Berhasil |
| 5 | Pencarian | Mencari data yang ada di database | Data yang dicari muncul di list | Berhasil |
| 6 | Hapus Data | Menghapus data yang sudah ada | Data terhapus dari database | Berhasil |
